# FeatureCards

Full-width section: a responsive grid of icon + title + text cards, optionally
under a banner image. Each item is wrapped in `Reveal` with alternating
directions, so it animates in on scroll.

`design.columns`: `3` (default) · `2` · `1`. Items carry `iconName` (see `Icon`),
`title`, `text`, and optionally `image` / `imageAlt`.
