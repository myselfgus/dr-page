# Input

Single-line field. **Never use it to collect health data** — the site has no
clinical form backend by design (LGPD art. 11). Legitimate uses are search and
newsletter-style fields.

Pair with a `font-mono text-xs uppercase tracking-widest text-muted-foreground`
label. `aria-invalid` switches the ring and border to the destructive token.
